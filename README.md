# Tanisha Tripathi — Personal Portfolio Website

An editorial, high-performance personal portfolio website for **Tanisha Tripathi** (Frontend Developer & React UI Engineer), inspired by **Dymas Alfin's** neo-minimalist typography, micro-interactions, and animations aesthetic.

---

## 🌟 Highlights & Key Features

- **Dymas Alfin Interaction Aesthetic**:
  - **Custom Magnetic Cursor**: Dual-ring cursor with smoothing inertia, ring dilation, and hover physics over interactive elements.
  - **3D Card Perspective Tilt**: Interactive 3D mouse tracking on the hero portrait card and project cards with dynamic perspective lighting.
  - **Scroll-Reveal Animations**: IntersectionObserver-driven viewport transitions with staggered entrance animations.
  - **Dynamic Ambient Glow**: Floating radial gradient light orbs and ambient noise texture.
  - **Infinite Tech Marquee**: Butter-smooth 60fps continuous horizontal slider showcasing core competencies and honors.
  - **Synthesized Tactile Audio FX**: Optional Web Audio API click synthesis with toggle button in the navigation header.

- **Content & Architecture (from Resume)**:
  - **Hero Section**: Live availability beacon, headline, quick metrics (3x Hackathons Won, Top 50 of 500+ teams, 8.56 SGPA at NIET, 100% Live Deployment), and Tanisha's professional portrait with achievement chips.
  - **Engineering Philosophy & Background**: Narrative overview, 4 core architectural pillars, and academic background (NIET Integrated B.Tech + M.Tech, Rani Laxmi Bai Memorial School).
  - **Selected Works & Systems (Projects)**:
    - **Belluna**: Bilingual (English/Hindi) Women's Health Web App (React, TypeScript, Tailwind CSS, Supabase, PostgreSQL RLS, Groq API, Leaflet, Vitest).
    - **SilentHelp**: AI-Powered Mental Health Support Platform (React, JavaScript, HTML5, CSS3, Conversational AI).
    - **CrowdCare**: Community Emergency Dispatch Platform (🏆 3x Hackathon Winner, Top 50 of 500+ Teams).
    - **LearnGecko Component Library**: Reusable responsive UI component system with systematic breakpoint tuning.
  - **Interactive Deep Dive Modals**: Dedicated modal view for each project featuring System Architecture, Technical Specs, Key Engineering Highlights, and Code links.
  - **Work Experience**: LearnGecko (Frontend Developer) and Ashna AI (Content Writer & AI Researcher).
  - **Technical Arsenal**: 6 categorized skill blocks (Languages, Frontend & UI/UX, Backend & Data, Tools & Testing, Core Engineering, Spoken Languages).
  - **Recognition & Achievements**: 3x Hackathon Winner, Academic Excellence (8.56 SGPA), Live Project Deployment.
  - **Print-Ready Curriculum Vitae Modal**: Interactive ATS-optimized modal viewer with a dedicated `@media print` print-to-PDF button.
  - **Contact & Collaboration Dock**: Direct one-click copy buttons for Email (`tanishatrip2015@gmail.com`) and Phone (`+91 88829 47997`) with animated toast notifications, real-time Indian Standard Time (IST) clock, and interactive contact form.

## 🚀 Running Locally

You can run this website with any static file server:

### Option 1: Python
```bash
python -m http.server 4173
```
Then navigate to [http://localhost:4173](http://localhost:4173) in your browser.

### Option 2: Node.js (npx serve)
```bash
npx serve .
```

### Option 3: VS Code Live Server
Right-click `index.html` and click **"Open with Live Server"**.
